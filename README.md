# 문자열 덧셈 계산기

## 기능 요구사항

- 입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

### 요구사항 세부 규칙

- 기본 구분자
    - 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
- 커스텀 구분자
    - 앞의 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수 있다. 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
- 예외 규칙
    - 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

## 해결해야 하는 문제 영역

- 사용자가 입력한 문자열을 파싱한다.
- 숫자를 더한 결과를 반환한다.

## 구현해야 하는 기능 목록

- 구체적인 비즈니스 로직(ex. 검증 규칙)을 포함하지는 않았습니다.
- 구체적인 비즈니스 로직은 요구사항 분석 문서에 따로 정리했습니다.

### 1. 입력 처리

- [x] 콘솔로부터 사용자에게 문자열을 입력받는다.

### 2. 구분자 처리

- [ ] 커스텀 구분자 영역이 존재하는지 판단하여, 커스텀 구분자를 분리할 수 있다.
    - [ ] 커스텀 구분자 영역이 존재하는지 판단한다.
        - [ ] 커스텀 구분자 영역의 포맷이 잘못된 경우 예외를 발생시킨다.
    - [ ] 커스텀 구분자 값을 찾는다.
        - [ ] 커스텀 구분자로 올 수 없는 문자가 포함된 경우 예외를 발생시킨다.

### 3. 숫자 추출 처리

- [ ] 모든 구분자를 바탕으로 숫자를 추출한다.
    - [ ] 숫자 영역의 포맷이 잘못된 경우 예외를 발생시킨다.
    - [ ] 숫자 영역에서 숫자 값을 찾는다.
        - [ ] 숫자 값이 잘못된 경우 예외를 발생시킨다.
- [ ] 숫자를 더한다.
    - [ ] 덧셈 결과를 검증한다.

### 4. 결과 출력

- [ ] 사용자에게 덧셈 결과를 콘솔애 출력함으로써 전달한다.
